# 部分诊断板块报告生成 - 使用指南

## 📖 功能说明

改造后的系统支持用户在**任何诊断板块完成后**即可生成报告，无需等待所有四诊都完成。

### 🎯 主要变化

| 原流程 | 新流程 |
|-------|--------|
| 必须完成所有四诊才能生成报告 | 完成任意1个板块即可生成报告 |
| 只能生成"四诊合参报告" | 可生成 "单板块报告" 或 "部分诊断报告" |
| 用户体验固定 | 用户可灵活选择完成策略 |

---

## 🔄 工作流程

### 场景1：用户希望快速获得初步报告

```
1. 进入诊断选择页面
   ↓
2. 完成【望诊（舌象分析）】
   - 拍照上传 → AI分析 → 完成
   ↓
3. 在结果页面点击【生成当前报告】
   ↓
4. 查看"单板块诊断报告 - 望诊"
   - 只显示舌象诊断的内容
   - 综合建议会建议补充其他诊断
   - 支持导出PDF或打印
```

### 场景2：用户分阶段完成诊断

```
1. 完成望诊 → 继续下一个诊断
2. 完成闻诊 → 继续下一个诊断  
3. 完成问诊 → 选择"生成报告 (3个板块)"
   ↓
4. 查看"部分诊断报告 (3/4板块)"
   - 显示完成度：75%
   - 显示已完成的3个诊断内容
   - 切诊部分显示"未进行"
```

### 场景3：用户完成全部四诊

```
1. 依次完成：望 → 闻 → 问 → 切
2. 返回诊断选择页 → 显示"已完成 4/4"
3. 点击【生成四诊合参报告】
   ↓
4. 查看完整的"四诊合参诊断报告"
   - 显示100%完成度
   - 所有四个诊断内容完整
   - 综合建议最全面
```

## 🎛️ 操作指南

### ✅ 完成诊断后的选择

#### Wang.vue（望诊）完成结果页面
```
结果显示：
┌──────────────────────────┐
│   ✓ 诊断完成             │
│                          │
│ 初步辨证结论：舌质淡红...│
│                          │
│ [采集样本图]  [辨证模型] │
│                          │
│ AI分析仅供参考，请咨询医生 │
│                          │
│ [重新分析] [继续下一个] [生成报告]│
└──────────────────────────┘
```

**按钮说明：**
- **重新分析**：重新拍照或上传，更新本板块诊断
- **继续下一个诊断**：返回诊断选择页，继续其他诊断
- **生成当前报告**：基于当前已完成的板块生成报告

### ✅ 从诊断选择页生成报告

1. 完成至少1个诊断板块后
2. 页面下方显示 "已完成 n/4" 的进度条
3. 点击 **"生成报告 (n个板块)"** 按钮
4. 等待AI生成综合诊断建议（约3-5秒）
5. 查看报告内容
6. 可导出PDF或打印

## 💡 建议使用方式

### 📋 场景A：快速初诊
**适用人群**：急诊患者、初次体验

1. 完成**望诊**（舌象）→ 1分钟
2. 立即生成报告 → 查看初步诊断
3. 后续补充其他诊断 → 更新报告

**优势**：快速获得初步诊断建议

---

### 📊 场景B：分次诊断
**适用人群**：复诊患者、逐步健康管理

1. 第一次就诊：完成望诊 + 闻诊 → 生成报告
2. 第二次就诊：完成问诊 + 切诊 → 生成完整报告
3. 对比两份报告 → 了解体质变化

**优势**：灵活适应就诊安排

---

### 🎯 场景C：完整诊断
**适用人群**：健康管理、中医调理

1. 完成所有四诊 → 生成四诊合参报告
2. 获得最全面的诊断建议
3. 定期复诊，跟踪调理效果

**优势**：诊断最全面，建议最针对性

---

## ⚠️ 注意事项

1. **诊断完成后不可修改**：
   - 点击已完成的板块会显示"结果已锁定"
   - 需要重新诊断请使用"重新分析"按钮

2. **报告综合建议的准确性**：
   - 板块越完整，AI生成的建议越准确
   - 部分诊断的建议会有"请补充其他诊断"的提示

3. **PDF导出**：
   - 部分诊断报告导出的PDF格式完全相同
   - 只是内容根据已完成板块调整

4. **多次生成报告**：
   - 后续完成其他诊断后可重新生成报告
   - 系统会基于最新的所有诊断数据

## 🆘 常见问题

**Q: 完成1个板块后能生成打印版报告吗？**  
A: 可以。在Report页面点击"打印"按钮，会打印当前显示的内容。

**Q: 已生成的报告能更新吗？**  
A: 能。完成其他诊断后，重新点击"生成报告"，系统会基于最新数据重新生成。

**Q: 部分诊断报告的综合建议不够全面怎么办？**  
A: 这是正常的。系统会在综合建议中建议您补充其他诊断。完成全部四诊后会获得更全面的建议。

**Q: 能否只生成某个特定板块的报告？**  
A: 可以。完成您想要的板块，然后直接点击"生成报告"。
