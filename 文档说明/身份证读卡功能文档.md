# 身份证读卡功能文档

## 功能概述
二代居民身份证读卡系统，通过x86 USB读卡器获取卡片信息（姓名、身份证号、照片等），经Python桥接和Java中转，在Vue前端展示已读取的身份证照片和信息。

---

## 系统架构

```
┌─ 前端（Vue3）
│  └─ 登记页/报告页：读卡交互 + 身份证图像展示
│
├─ Java Spring Boot 中转
│  └─ /api/idcard/read：代理、格式转换、包装Result
│
├─ C# .NET x86 读卡服务（127.0.0.1:9009）
│  └─ 物理硬件交互：SDT_* DLL调用 → 照片解码 → SVG卡片生成
│
└─ Python 桥接（可选，当主服务为64位时启用）
   └─ 127.0.0.1:19081：32位进程代理读卡DLL调用
```

#### `Services/IdCardDllWrapper.cs`
**作用**：厂商SDK DLL P/Invoke 封装与常量定义

**常量定义**：
```csharp
public const byte SDT_FIND_CARD_SUCCESS = 0x9F;  // 寻卡成功（非标准！）
public const byte SDT_SUCCESS = 0x90;            // 标准成功码（选卡、读卡等）
public const byte SDT_SELECTCARD = 0x9F;         // 选卡成功
```

**P/Invoke方法**：
```csharp
[DllImport("sdtapi.dll")] 
public static extern byte SDT_OpenPort(int port);
[DllImport("sdtapi.dll")] 
public static extern byte SDT_StartFindIDCard(int port, byte[] manaInfo, int len);
[DllImport("sdtapi.dll")] 
public static extern byte SDT_SelectIDCard(int port, byte[] manaMsg, int len);
[DllImport("sdtapi.dll")] 
public static extern byte SDT_ReadBaseMsg(int port, byte[] msg, ref uint msgLen);
[DllImport("DLL_File.dll")] 
public static extern int unpack(byte[] input, int inputLen, byte[] output, ref int outputLen);
```

**关键函数**：
- `IsFindCardSuccess(byte code)`: 检验 SDT_StartFindIDCard 返回码（识别0x9F为成功）
- `IsSdtSuccess(byte code)`: 检验其他操作返回码（标准 0x90）
- `GetErrorMessage(byte code)`: 将错误码转为中文错误消息
- `ParseNation(byte code)`: 将01-56民族代码转为中文名（01→汉族，02→蒙古族等）

#### `Services/IdCardReaderService.cs`
**作用**：核心业务逻辑 - 读卡流程编排

**主方法：`ReadIdCardAsync()`**

执行流程：
1. **端口初始化** → `EnsureReaderConnected()` 找到可用COM端口
2. **寻卡** → `SDT_StartFindIDCard()` 返回 0x9F 表示成功
3. **选卡** → `SDT_SelectIDCard()` 返回 0x90 表示成功
4. **读取中文区** → `SDT_ReadBaseMsg()` 返回 UTF-16LE编码的中文区 + 照片压缩数据
5. **解析文本** → `ParseChineseMessage()` 提取 姓名、性别、民族、生日、地址等
6. **解码照片** → `unpack()` 解压缩照片数据，转换BGR→BMP
7. **生成SVG** → `BuildIdCardPreviewDataUrl()` 生成整卡预览图
8. **返回** → `IdCardInfo` 包含所有字段

**子方法详解**：

- `EnsureReaderConnected()`: 
  - 尝试打开 COM1-COM4（某些USB适配器表现为虚拟COM口）
  - 在 USB 1001 上备选
  - 设置 `_openedPort` 和 `_isConnected` 标志

- `ParseChineseMessage(byte[] chMsg)`:
  - 输入：UTF-16LE编码的中文数据块（256字节）
  - 使用硬编码偏移提取字段：
    - 姓名：offset 0, length 15
    - 性别：offset 15, length 1（M/F/未说明）
    - 民族：offset 16, length 2（01-56代码）
    - 出生日期：offset 18, length 8（YYYYMMDD）
    - 地址：offset 26, length 35
    - 身份证号：offset 61, length 18
    - 发证机关：offset 79, length 15
    - 有效期开始：offset 94, length 8
    - 有效期结束：offset 102, length 8
  - 返回：映射后的 `IdCardInfo`

- `BuildBmpFromBgr(byte[] bgr)`:
  - **输入**：BGR格式像素数据（102×126×3字节）
  - **处理**：
    1. 计算行宽带（stride），每行必须4字节对齐 → (102×3+3)/4×4 = 308 字节
    2. 构建BMP文件头（54字节）：
       - 高度为负（-126）表示 top-down 编码
       - 宽度 102, 高度 126, 颜色深度 24bit
    3. **行反转**：循环遍历像素时反向行顺序（修复上下倒置问题）
    4. 生成 `data:image/bmp;base64,{base64_encoded_bmp}`
  - **返回**：可直接嵌入HTML的data URL

- `BuildIdCardPreviewDataUrl()`:
  - 生成 720×454 SVG 整卡图像
  - 绘制卡面：背景、标题、文字标签、边框
  - 头像框位置：x=500, y=112, width=176, height=220
  - 内部头像位置：x=509, y=121（略有偏移以留边距）
  - 嵌入 BMP 头像作为 `<image>` 标签（href使用data URL）
  - 返回 `data:image/svg+xml;base64,{base64_encoded_svg}`

#### `Controllers/IdCardController.cs`
**作用**：HTTP API 路由层

**端点列表**：

1. **`GET /api/idcard/read`**
   - 调用 `IdCardReaderService.ReadIdCardAsync()`
   - 包装返回 `ApiResponse<IdCardInfo>` 格式
   - 包含 Success, Message, Data 三个字段
   - 异常时返回 HTTP 500 + 错误消息

2. **`GET /api/idcard/status`**
   - 调用 `IsReaderConnectedAsync()`
   - 返回 `{ success: true/false, message: "已连接/未连接", data: null }`

3. **`GET /api/idcard/health`**
   - 调用 `GetReaderStatusAsync()`
   - 返回详细状态（SDK版本、端口、DLL路径等）
   - 用于诊断连接问题

4. **`POST /api/idcard/release`**
   - 调用 `ReleaseReaderAsync()`
   - 手动释放COM端口（通常自动关闭，备用）

## 关键技术细节

### 1. 二代证SDK读卡流程
- **寻卡**：`SDT_StartFindIDCard()` → 返回 `0x9F` (成功) 或 `0x90`
- **选卡**：`SDT_SelectIDCard()` → 返回 `0x90` (成功) 或错误码
- **读取**：`SDT_ReadBaseMsg()` 返回中文区（UTF-16LE）+ 照片压缩数据
- **照片解码**：`unpack()` 需 `license.dat` 和 `DLL_File.dll`

### 2. 照片格式处理
- **原始**：芯片压缩数据 → `unpack()` 解码 → BGR 格式 (102×126×3 字节)
- **BMP 编码**：
  - BMP 文件头 (54 字节) + 像素数据
  - **修正**：添加行对齐（4字节倍数）和倒序（top-down）
  - **格式**：`data:image/bmp;base64,...`
- **SVG 预览**：后端生成整卡设计，嵌入 `<image>` 标签显示头像

### 3. 民族代码映射
- 二代证存储 01-56 数字代码（如 01=汉族, 02=蒙古族）
- 已映射全部56个民族中文名称
- 应用于 SQL 存储和前端显示

### 4. 跨进程调用（桥接）
- **64位主服务** + **32位DLL** → 启用桥接
- 桥接进程监听 `http://127.0.0.1:19081`
- 64位 Python 通过 HTTP 代理 32 位 DLL 调用

## 常见问题

### Q: 为什么头像歪斜/显示不正常？
**A**: 已修正 BMP 编码的行对齐与倒序问题。需重启 C# 服务。

### Q: 读卡返回"寻卡失败 0x9F"？
**A**: 0x9F 是该SDK的成功码（非标准0x90）。已在代码中处理。

### Q: 如何获取整张身份证图像（非单独头像）？
**A**: 后端生成 SVG 卡片预览（包含文字+头像），返回 `IdCardImageBase64`。前端优先显示 SVG，兜底显示头像。

### Q: 前端看不到身份证照片？
**A**: 
1. 确保 C# 服务运行正常（`GET http://127.0.0.1:9009/api/idcard/health`）
2. 检查浏览器 localStorage 是否保存了 `current_idcard_image_base64`
3. 刷新页面重试
